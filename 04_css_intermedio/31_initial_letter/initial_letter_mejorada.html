Propiedad CSS initial-letter

Ajusta el tamaño y posición de las letras iniciales en párrafos

¿Qué es initial-letter?

La propiedad initial-letter de CSS establece el tamaño y el hundimiento de las letras iniciales caídas, elevadas y hundidas. Esta propiedad se aplica a ::first-letter pseudoelementos y primeros elementos secundarios en línea de contenedores de bloques.

Esta propiedad es especialmente útil para diseños editoriales y periodísticos donde se busca dar un estilo elegante a los párrafos iniciales de un texto, emulando el estilo de los libros y revistas impresas.

Nota sobre compatibilidad:

La propiedad initial-letter actualmente tiene soporte limitado en navegadores. Funciona principalmente en Safari. Para otros navegadores, hemos implementado un fallback que simula un efecto similar usando float y tamaño de fuente.

Valores y ejemplos

Keyword value

initial-letter: normal;
Este es un ejemplo de texto con initial-letter establecido como normal. La primera letra no tendrá un estilo especial.

Un valor (altura de línea)

initial-letter: 3; /* 3 líneas de alto, baseline en línea 3 */
Este es un ejemplo de texto con initial-letter establecido en 3. La primera letra ocupará tres líneas de alto.

Dos valores (altura y posición)

initial-letter: 3 2; /* 3 líneas de alto, baseline en línea 2 */
Este es un ejemplo de texto con initial-letter establecido en 3 2. La primera letra ocupará tres líneas de alto con el baseline en la segunda línea.
