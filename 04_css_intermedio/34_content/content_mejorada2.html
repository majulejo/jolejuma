Botones con Etiquetas en Diferentes Posiciones

Ejemplos de cómo utilizar la propiedad CSS content con pseudo-elementos para agregar etiquetas a botones en diversas posiciones.

Esquina Superior Derecha

.btn.top-right::after {
  content: "Nuevo";
  position: absolute;
  top: -12px;
  right: -15px;
  /* Estilos adicionales */
}

Esquina Superior Izquierda

.btn.top-left::before {
  content: "Oferta";
  position: absolute;
  top: -12px;
  left: -15px;
  /* Estilos adicionales */
}

Esquina Inferior Derecha

.btn.bottom-right::after {
  content: "Popular";
  position: absolute;
  bottom: -12px;
  right: -15px;
  /* Estilos adicionales */
}

Esquina Inferior Izquierda

.btn.bottom-left::before {
  content: "Limited";
  position: absolute;
  bottom: -12px;
  left: -15px;
  /* Estilos adicionales */
}

Arriba Centrada

.btn.top-center::before {
  content: "Premium";
  position: absolute;
  top: -35px;
  left: 50%;
  transform: translateX(-50%);
  /* Estilos adicionales */
}

Abajo Centrada

.btn.bottom-center::after {
  content: "Gratis";
  position: absolute;
  bottom: -35px;
  left: 50%;
  transform: translateX(-50%);
  /* Estilos adicionales */
}

Dentro del Botón (Derecha)

.btn.inside-right::after {
  content: "→";
  margin-left: 10px;
  font-weight: bold;
}

Dentro del Botón (Izquierda)

.btn.inside-left::before {
  content: "←";
  margin-right: 10px;
  font-weight: bold;
}

Múltiples Etiquetas

.btn.multiple::before {
  content: "Hot";
  /* Posición superior izquierda */
}

.btn.multiple::after {
  content: "Sale";
  /* Posición inferior derecha */
}
