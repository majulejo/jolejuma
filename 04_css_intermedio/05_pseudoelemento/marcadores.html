Pseudoelementos CSS

Explicación y demostración de pseudoelementos como ::marker, ::before, ::after y más.

Código Original

    padding: 5px;
}

    color:#800;
    font-size: 3em;
    letter-spacing: 8px;
}
div::first-line {
    color:#080;
    font-weight: bold;
}
div::selection{
    background-color: #cbd113;
    color: #65d113 ;
}
input::placeholder{
    color:#008;
    background-color:#bfe0a6 ;
}
li::marker{
    color:#f79cd1;
}
li::before{
    content: "Antes: ";
    color:#2507eb;
    padding-right: 60px;
}
li::after{
    content: "Después ";
    color:#33b57d;
    margin-left: 45px;
    background-color: #cbd113;
}

¿Qué hace li::marker?

El pseudoelemento ::marker aplica estilos al marcador de los elementos de lista (las viñetas en listas no ordenadas y los números en listas ordenadas).

En este caso, li::marker { color: #f79cd1; } cambia el color de todos los marcadores de elementos de lista a un tono rosa claro.

Los pseudoelementos permiten aplicar estilos a partes específicas de un elemento sin necesidad de agregar HTML adicional. En este ejemplo, también se utilizan:

  • ::first-letter - para la primera letra del título
  • ::first-line - para la primera línea de los párrafos
  • ::selection - para el texto seleccionado
  • ::placeholder - para el texto de marcador de posición en inputs
  • ::before - para insertar contenido antes de los elementos de lista
  • ::after - para insertar contenido después de los elementos de lista
