Pseudo-elementos CSS

Explora los diferentes pseudo-elementos CSS y cómo pueden mejorar el diseño de tu sitio web.

::first-letter

Título de ejemplo

h1::first-letter {
  color: #800;
  font-size: 3em;
  letter-spacing: 8px;
}

::first-letter aplica estilos a la primera letra de un elemento de bloque. En este ejemplo, la primera letra del título es más grande, de color granate y con mayor espaciado.

::first-line
Este es un ejemplo de texto donde la primera línea tiene un estilo especial. Si la ventana es lo suficientemente ancha, solo la primera línea será verde y en negrita. Si ajustas el tamaño de la ventana, verás cómo cambia la primera línea.
div::first-line {
  color: #080;
  font-weight: bold;
}

::first-line aplica estilos a la primera línea de un elemento de bloque. Los estilos se ajustan automáticamente cuando cambia el tamaño de la ventana.

::selection
Selecciona este texto para ver el efecto. El fondo de la selección será amarillo verdoso y el texto se volverá verde claro.
div::selection {
  background-color: #cbd113;
  color: #65d113;
}

::selection aplica estilos a la porción de un documento que ha sido resaltado por el usuario (por ejemplo, al seleccionar texto con el mouse).

::placeholder
input::placeholder {
  color: #008;
  background-color: #bfe0a6;
}

::placeholder aplica estilos al texto de marcador de posición en elementos de entrada. En este ejemplo, el texto del placeholder es azul con fondo verde claro.

::marker, ::before y ::after
  • Elemento de lista 1
  • Elemento de lista 2
  • Elemento de lista 3
li::marker {
  color: #f79cd1;
}

li::before {
  content: "Antes: ";
  color: #2507eb;
  padding-right: 60px;
}

li::after {
  content: "Después ";
  color: #33b57d;
  margin-left: 45px;
  background-color: #cbd113;
}

::marker aplica estilos al marcador de elementos de lista. ::before inserta contenido antes del elemento, y ::after inserta contenido después del elemento.
