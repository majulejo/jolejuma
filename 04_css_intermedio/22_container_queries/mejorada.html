¿Qué son las Container Queries?

Las Container Queries son una característica de CSS que permite aplicar estilos a un elemento basedo en el tamaño de su contenedor padre, en lugar de basarse en el tamaño del viewport (como lo hacen las Media Queries).

Esto es especialmente útil para componentes reutilizables que pueden aparecer en diferentes partes de una layout con diferentes tamaños disponibles.

/* Definir el contenedor */
.container {
  container-type: inline-size;
  container-name: mi-contenedor;
}

/* Aplicar estilos según el tamaño del contenedor */
@container mi-contenedor (max-width: 500px) {
  .elemento {
    /* Estilos para contenedores pequeños */
  }
}
