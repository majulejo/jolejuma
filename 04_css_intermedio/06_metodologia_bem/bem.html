¿Qué hace list-style: disclosure-closed?

Esta propiedad CSS cambia las viñetas de la lista a un triángulo cerrado (▶), que normalmente se usa para indicar elementos colapsables. Sin embargo, tiene compatibilidad limitada (solo funciona en Firefox).

En esta demostración, hemos usado pseudo-elementos para simular el mismo efecto con mejor compatibilidad entre navegadores.
